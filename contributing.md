## 🆔 The Ban Follows The Board, Not The Disk

Most people reformat Windows, reinstall the game, make a new account — and get
banned again within a session. Here is why that happens, and what has to change.

**What a cleanup actually reaches**

| **Action** | **Clears** | **Misses** |
| --- | --- | --- |
| Reinstall the game | game files | everything below |
| New Windows install | OS identifiers | firmware, NIC, disk |
| New account | account record | the machine entirely |
| New drive | volume serial | board UUID, NIC, GPU |
| New motherboard | board UUID | NIC, GPU, disk |

**The layer that survives all of it**

Board and device firmware. Those identifiers are read during boot and stored in
places a reinstall does not touch. They are also the ones the ban list is keyed
on, which is why a clean machine keeps getting caught.

**What this build targets**

The firmware and device layer specifically — the ones that survive a reformat.
That is the only layer where a reset changes the outcome.

**The verification step**

After the reset and a reboot, the identifiers must differ from what they were. If
they do not, the reset did not reach the firmware layer and the next account will
be burned the same way. Check before you commit an account to it.
